# Unit Outline Dashboard

A personal Semester 2, 2026 Curtin dashboard built from the unit outlines for:

- ACCT2002 — Cost Analysis for Decision Making
- ECOM1000 — Analytics for Decision Making
- TAXA2000 — Introduction to Australian Taxation Law
- ECON1000 — Introductory Economics

The dashboard shows the current teaching week, upcoming deadlines, weekly topics, assessment weights, unit quick-reference information, and a local checklist stored in the browser.

Dates are shown in AWST. Blackboard and OASIS remain the authoritative source for any later changes to assessment dates or exam scheduling.
